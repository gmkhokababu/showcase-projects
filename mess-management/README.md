# Mess Management System

This project is designed to manage daily mess or canteen operations efficiently, including member records, food management, and service tracking.

## Project Overview

The system is focused on managing routine mess operations, member records, meal distribution, and daily administration. It helps organize operations for a shared canteen or hostel setup.

## Tech Stack

### Frontend
- HTML / CSS / JavaScript
- Angular

### Backend
- Java
- Spring Boot

### Database
- MySQL

## Main Features

- Member or user record management
- Meal and menu tracking
- Daily operations management
- Billing or payment tracking
- Reporting and summary views

## Project Goals

This project helped me learn:
- Operational workflow design
- Daily service management systems
- Data organization and reporting
- Practical application logic for utility software

## Project Status

Completed as a daily operations focused project.
