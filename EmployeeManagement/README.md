# Employee Management System

This project is designed to manage employee information, work records, departments, attendance, and organizational data in a single system.

## Project Overview

An employee management system helps businesses maintain employee profiles, department information, and key operational records efficiently. It is useful for administrative control and workforce organization.

## Tech Stack

### Frontend
- HTML / CSS / JavaScript
- Angular

### Backend
- Java
- Spring Boot

### Database
- MySQL

## Main Features

- Employee registration and profile management
- Department and role assignment
- Attendance or work tracking
- Salary and task-related record management
- Search and reporting utilities
- Admin dashboard support

## Project Goals

This project helped me learn:
- CRUD-based application design
- Business data modeling
- User and admin role separation
- Data validation and reporting

## Project Status

Completed as a practical management application and showcase project.
