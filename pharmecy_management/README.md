# Pharmacy Management System

This project is a pharmacy management system designed to handle medications, inventory, sales, and essential daily store operations.

## Project Overview

The system helps manage pharmaceutical stock, medicine records, sales activities, and inventory updates in a structured way. It is useful for retail pharmacy or healthcare support workflows.

## Tech Stack

### Frontend
- Angular
- HTML / CSS / JavaScript

### Backend
- Java
- Spring Boot

### Database
- MySQL

## Main Features

- Medicine inventory tracking
- Sales and billing management
- Product stock updates
- Customer and transaction records
- Reporting and summary dashboard

## Project Goals

This project helped me understand:
- Inventory-based business systems
- Transaction and stock management
- Healthcare retail workflow design
- Full-stack management application development

## Project Status

Completed as a healthcare retail management project and portfolio showcase item.
