# Hotel Management System

This project is built to manage hotel operations, rooms, reservations, customer information, and service workflows.

## Project Overview

A hotel management system supports daily operations such as room booking, guest tracking, service coordination, and administrative reporting. It helps streamline the management of hospitality-related tasks.

## Tech Stack

### Frontend
- Angular
- TypeScript
- HTML / CSS

### Backend
- Java
- Spring Boot

### Database
- MySQL

## Main Features

- Room management and availability tracking
- Guest and booking details
- Reservation management
- Service and billing procedures
- Staff and room assignment workflows
- Dashboard summary and reporting

## Project Goals

This project helped me improve my understanding of:
- Real-world business logic design
- Booking and reservation systems
- Workflow and state management
- UI and backend integration

## Project Status

Completed as a hospitality-focused project for practical development experience.
