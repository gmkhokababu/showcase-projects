# Restaurant Management System

This project is a restaurant management application focused on ordering, service coordination, menu handling, and operational control.

## Project Overview

The system is designed to support restaurant operations by managing menu items, customer orders, services, and overall business workflow. It helps improve the efficiency of daily restaurant management.

## Tech Stack

### Frontend
- Angular
- TypeScript
- HTML / CSS

### Backend
- Java
- Spring Boot

### Database
- MySQL

## Main Features

- Order and customer management
- Menu and category management
- Billing and transaction tracking
- Staff and service-related operations
- Inventory or stock monitoring
- Reporting and summary dashboard

## Project Goals

This project helped me understand:
- Service-based business workflows
- Real-time order handling concepts
- Database relationships for transactions
- Full-stack application development

## Project Status

Completed as a business-process management project for practical implementation.
